Web to Figma

웹페이지를 편집 가능한 피그마 레이어로 복사하는 크롬 확장 프로그램. 스크린샷 이미지가 아니라, 텍스트는 텍스트로 아이콘은 벡터로 들어갑니다.

GitHub 저장소 설치 방법

사용법

플러그인 설치도, 파일 내보내기도 필요 없습니다. 복사 → 붙여넣기가 전부입니다.

  1. 확장 아이콘 클릭캡처할 웹페이지에서 툴바의 아이콘을 누릅니다.
  2. 범위와 해상도 선택페이지 전체 또는 특정 영역(클릭으로 지정). 해상도는 현재 브라우저 그대로 또는 390~3440px 프리셋.
  3. 클립보드로 복사버튼 하나로 변환이 끝납니다.
  4. 피그마에서 Ctrl + V레이어 구조가 그대로 붙습니다. 바로 편집할 수 있습니다.

무엇이 그대로 들어오나

붙여넣는 즉시 렌더됩니다. 별도 후처리가 필요하지 않습니다.

텍스트

글자·색상·크기·굵기·자간·줄바꿈까지. 이미지가 아닌 실제 텍스트 레이어입니다.

벡터 아이콘

SVG 아이콘은 진짜 벡터 패스로. 구멍 뚫린 도형(돋보기 등)도 정확하게 재현됩니다.

레이아웃 · 스타일

DOM 계층 구조를 유지한 프레임 트리. 배경색·테두리·모서리 라운드·절대 좌표 그대로.

390 / 768 / 1440 / 1920 / 2560 / 3440px. 지정한 너비로 페이지를 재배치해 최하단까지 캡처합니다.

알아두면 좋은 점

  • 이미지는 평균 색상 플레이스홀더로 들어옵니다. 클립보드 형식 자체가 이미지 원본 데이터를 담지 못하기 때문입니다.
  • 그라디언트·그림자는 아직 지원하지 않습니다.
  • 페이지가 매우 크면 노드 수가 많아 변환에 몇 초 걸릴 수 있습니다. 영역 선택을 쓰면 빠릅니다.
  • 캡처한 데이터는 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.
