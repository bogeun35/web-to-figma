개인정보처리방침

최종 수정일 2026-07-26 · Privacy Policy

한국어

Web to Figma는 개인정보를 수집하지 않습니다.

데이터 처리

  • 캡처한 웹페이지의 내용(텍스트, 스타일, 좌표, 이미지 색상)은 사용자의 브라우저 안에서만 처리됩니다.
  • 처리 결과는 사용자의 클립보드에만 기록됩니다.
  • 개발자를 포함한 어떤 서버로도 데이터를 전송하지 않습니다. 확장 프로그램에는 외부 전송 코드가 없습니다.
  • 분석 도구, 추적 코드, 광고를 사용하지 않습니다.

로컬 저장

다음 항목만 브라우저 로컬 저장소에 보관되며, 확장 프로그램을 삭제하면 함께 제거됩니다.

  • 선택한 인터페이스 언어
  • 마지막으로 선택한 캡처 영역의 CSS 선택자

네트워크 요청

캡처를 실행할 때, 현재 페이지에 이미 표시된 이미지의 평균 색상을 계산하기 위해 해당 이미지 주소로 요청을 보냅니다. 이 요청은 색상 계산에만 사용되며 결과는 저장되거나 전송되지 않습니다.

English

Web to Figma does not collect any personal data.

Data handling

  • Captured page content (text, styles, coordinates, image colors) is processed entirely within your browser.
  • The result is written only to your clipboard.
  • No data is transmitted to any server, including the developer's. The extension contains no code that sends data anywhere.
  • No analytics, tracking, or advertising.

Local storage

Only the following are stored locally in your browser and are removed when you uninstall the extension:

  • Selected interface language
  • CSS selector of the most recently picked capture area

Network requests

When you run a capture, the extension fetches images that are already displayed on the current page in order to compute their average color. These requests are used only for color calculation; nothing is stored or transmitted.
